# notebooks/

Your exploration lives here. Week 2 is an EDA notebook: load the three CSVs,
plot the plan-paid distribution on a log scale, find the prevalence of the
positive class in your own cohort.

Notebooks are for looking at things. Anything you need to *run again* — feature
engineering, training, evaluation — belongs in the `.py` files at the repo root, which
is where the tests can reach it.

Commit your notebooks. `.ipynb_checkpoints/` is already gitignored.
